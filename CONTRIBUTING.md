# Contributing

For substantive changes preserve an Issue → PR → tests/evidence → merge trail. State the profile proposition or defect, authority/compatibility/assurance impact and acceptance criteria; implement the smallest coherent change; add deterministic positive/negative evidence where consequential; and merge only after applicable validation passes.

Do not turn missing or stale evidence into PASS, and do not silently broaden profile authority beyond the scope declared in `GOVERNANCE.md` and `UPSTREAM.md`.

Security reports must follow [`SECURITY.md`](SECURITY.md).
