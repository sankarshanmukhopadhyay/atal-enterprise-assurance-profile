# v0.5.0 — Assurance Claims

## Release outcome

v0.5.0 changes EAP from a checklist-and-report workflow into a deployment-scoped assurance claim system.

## Added

- `schemas/deployment-profile.schema.json` — explicit deployment, autonomy, impact, environment, and authority declaration.
- `schemas/assurance-claim.schema.json` — bounded claim contract with lifecycle, evidence digests, and revocation fields.
- `scripts/derive_assurance_level.py` — deterministic minimum assurance-level derivation.
- `docs/assurance-claim-model.md` — authority separation and claim lifecycle semantics.

## Assurance impact

An EAP result is now attributable to a specific deployment and authority set. Assurance level selection becomes risk-derived rather than purely discretionary. Claims can expire or be revoked without deleting historical evidence.

## Validation

```bash
python scripts/derive_assurance_level.py <deployment-profile.json>
```
