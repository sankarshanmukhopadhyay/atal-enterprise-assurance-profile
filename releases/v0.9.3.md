# v0.9.3 — Reproducible Assessment

## Release outcome

v0.9.3 makes the EAP-L3 assurance claim independently reproducible from a bounded, digest-addressed assessor handoff.

## Added

- `schemas/assessor-handoff.schema.json` — machine-readable handoff contract.
- `assurance/handoff-source-set.yaml` — bounded source set for independent verification.
- `scripts/build_assessor_handoff.py` — deterministic manifest construction with SHA-256 bindings.
- `scripts/verify_assessor_handoff.py` — independent verification of integrity, completeness, profile/version, authority and lifecycle semantics.
- `tests/fixtures/handoff/tampered-digest.json` — deliberate digest-tamper fixture that must be rejected.
- machine-readable verification and tamper-rejection reports.
- `docs/independent-assessor-handoff.md` — verifier and authority-boundary guidance.

## Changed

- L3 claim generation derives the current repository version from `PROJECT-STATUS.yaml` rather than embedding a release number.
- the canonical quality gate builds and verifies the handoff and executes the tamper self-test.

## Assurance impact

A claim can now be handed to a separate verifier with an explicit source boundary. Verification can detect missing or changed evidence, mismatched claim scope, stale validity, revocation, and authority/profile drift without relying on undocumented repository state.

## Validation

```bash
python scripts/build_l3_assurance_claim.py
python scripts/build_assessor_handoff.py
python scripts/verify_assessor_handoff.py --tamper-self-test
python scripts/run_quality_gate.py --mode all
```

## Release evidence

A publishable v0.9.3 commit must pass the canonical quality gate and generate a verified assessor handoff plus a machine-readable rejection report for the tampered fixture.

## Authority boundary

Independent verification establishes handoff integrity and reproducibility only. It does not certify a deployment, accept enterprise risk, grant regulatory approval, or supersede upstream ATAL authority.
