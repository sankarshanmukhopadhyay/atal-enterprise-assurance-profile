# v0.8.0 — Enterprise Interoperability

## Release outcome

v0.8.0 introduces auditable external-framework mappings without asserting certification, legal compliance, or normative equivalence.

## Added

- `mappings/external-framework-mappings.yaml` — typed, confidence-scored mappings to NIST AI RMF 1.0, ISO/IEC 42001:2023, ISO/IEC 23894:2023, and the EU AI Act.
- `schemas/external-framework-mapping.schema.json` — mapping contract.
- `scripts/validate_external_mappings.py` — validation of control references, framework references, duplicates, and inconsistent confidence claims.

## Mapping rule

External-framework relationships are evidence-routing aids. They MUST NOT be represented as certification, regulatory approval, or proof that satisfying an EAP control satisfies the mapped external requirement.

## Assurance impact

Interoperability becomes reviewable evidence rather than an unqualified crosswalk table. Each mapping carries relationship strength, confidence, and rationale so downstream consumers can decide how much reliance is appropriate.

## Validation

```bash
python scripts/validate_external_mappings.py
```
