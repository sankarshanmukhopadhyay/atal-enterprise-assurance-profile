# Security Policy

Security and assurance-integrity fixes are applied to current `main` and the latest supported profile/release identified by repository status metadata. Older versions should be treated as unsupported unless a maintainer explicitly states otherwise.

Do not disclose undisclosed vulnerabilities in public issues. Use GitHub private vulnerability reporting when available, or contact the repository maintainer through a private channel identified on the maintainer profile.

Include affected revision/profile, reproduction steps, impact, affected assurance artifacts/evidence, and any known mitigation.

This repository defines an enterprise assurance profile and derived artifacts; it is not an external certification authority. A defect that could alter assurance claims, evidence admissibility, compatibility, delegation/authority boundaries or profile outcomes must identify affected evidence and must not silently preserve a stale PASS.
