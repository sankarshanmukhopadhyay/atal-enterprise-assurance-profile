# v0.6.0 — Evidence Strength

## Release outcome

v0.6.0 introduces an explicit evidence-strength model so EAP assessments can distinguish unsupported assertions from documentary, configuration, runtime, independently reproducible, and externally attested evidence.

## Added

- `evidence/evidence-strength-model.yaml` — E0–E5 evidence taxonomy, level minimums, and freshness expectations.
- `scripts/grade_evidence_bundle.py` — machine-readable evidence-strength report with optional fail-closed enforcement.

## Evidence grades

| Grade | Meaning |
|---|---|
| E0 | Assertion only |
| E1 | Documentary |
| E2 | Configuration/static |
| E3 | Machine-generated execution |
| E4 | Independently reproducible |
| E5 | Externally attested |

## Assurance impact

Evidence strength is now separable from control status. A `pass` supported only by weak evidence can be identified and, in strict mode, rejected. EAP-L1, L2, and L3 now have progressively stronger default evidence expectations.

## Validation

```bash
python scripts/grade_evidence_bundle.py evidence/samples/eap-l1-sample-evidence-bundle.json
python scripts/grade_evidence_bundle.py <bundle.json> --strict
```
