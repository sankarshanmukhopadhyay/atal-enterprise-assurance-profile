# v0.4.0 — Assurance Provenance

## Release outcome

v0.4.0 establishes a machine-verifiable provenance boundary between the ATAL Enterprise Assurance Profile and the upstream ATAL Standard.

## Added

- Exact upstream ATAL v0.9 commit pin in `upstream/atal-baseline.yaml`.
- JSON Schema for the upstream baseline declaration.
- `scripts/check_upstream_integrity.py` for fail-closed validation of release provenance.
- Quality-gate integration for provenance validation.

## Changed

- `UPSTREAM.md` now records a concrete v0.4.0 compatibility declaration instead of placeholders.
- `PROJECT-STATUS.yaml` now reflects the repository's executable validation commands and evidence outputs.

## Assurance impact

A release can no longer be considered complete while its normative ATAL baseline is unresolved. EAP explicitly distinguishes upstream ATAL semantic authority from EAP profile, mapping, test, evidence, and claim authority.

## Compatibility

- Upstream: ATAL Public Review Draft v0.9
- Commit: `bafb65d716ddf71d2a90defbd4bfb5064c6aee0e`
- Class: Extended Compatible

python scripts/check_upstream_integrity.py
python scripts/run_quality_gate.py --mode validate
