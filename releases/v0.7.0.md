# v0.7.0 — Executable Assurance

## Release outcome

v0.7.0 turns selected assurance requirements into portable, adapter-neutral conformance vectors and defines a machine-readable result contract.

## Added

- `schemas/test-case.schema.json` — declarative test-vector contract.
- `schemas/test-result.schema.json` — normalized execution-result contract.
- `tests/catalog/EAP-TEST-KS-001.yaml` — kill-switch effectiveness vector.
- `tests/catalog/EAP-TEST-NB-001.yaml` — non-bypassability vector.
- `scripts/validate_test_catalog.py` — fail-closed catalog validation and duplicate-ID detection.

## Assurance impact

Controls can now bind to reproducible stimuli, observations, pass conditions, and expected evidence strength. Implementations can provide adapters without changing the normative test definition, enabling cross-vendor reproducibility.

## Validation

```bash
python scripts/validate_test_catalog.py
```
